# 🗺️ 系统架构师备考 · 学习资料

| 文件 | 内容 |

| `架构知识地图.html` | 全部知识点汇总（主线图 / 质量属性 / 架构风格与模式 / 4+1视图 / 微服务 / 分布式 / 论文句式 / 易错速查），章节树 + hash 路由，桌面左侧菜单 / 手机抽屉菜单 |

## 访问方式

- **在线访问（推荐）**：部署 Gitee Pages 后访问
  `https://qguo2020.gitee.io/sad-notes/架构知识地图.html`
