# 🎓 软考系统架构师备考资料

四套主教材，一页直达。核心理念：**用最少的时间通过考试 —— 45 分万岁，飘过也算过**。

## 📚 模块说明

| 页面 | 内容 | 分值 |
|------|------|:---:|
| `index.html` | **首页**：四模块入口 + 备考路线建议 + 时间划分 + 飘过指南 | — |
| `架构知识地图.html` | **综合知识**：教材 11 章考点全覆盖（架构风格 / 质量属性 / 微服务 / 分布式 / 安全 / AI），含 11 张图表、章节树导航、全站搜索 | 选择题 75 分 |
| `案例题库.html` | **案例分析**：方法论 + 五大题型 + 根因-方案对照 + 高频考点清单 + 经典案例（题目 / 采分点 / 示范答案） | 案例 75 分 |
| `论文题库.html` | **论文写作**：考试流程 + 五段式结构 + 万能句式库 + 素材映射 + 提纲/摘要/正文段范文 + 练习计划 | 论文 75 分 |
| `缩写速查.html` | **缩写速查**：常考 / 必考 / 易错缩写（英文全称 + 中文含义 + 直达考点链接） | 随身速查 |

## 🚀 备考路线（详见首页）

| 时间预算 | 策略 |
|---------|------|
| **<15 天** | 只攻必考章节 + 案例套路 + 论文提纲（放弃冷门章节） |
| **15-30 天** | 11 章快速过一遍 + 练 5 道案例 + 写 2 篇论文 + 2 套真题 |
| **30 天以上** | 全覆盖 + 案例专项 + 论文 3 篇 + 模拟卷冲刺 |

**三科权重**：综合 40% / 案例 30% / 论文 30%（论文千万别空着）
